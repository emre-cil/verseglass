# Players

[English](players.md) · [Türkçe](tr/players.md)

**Spotify desktop.** Used while Spotify is actually playing. A paused Spotify app does not hide another player.

**YouTube and YouTube Music in a browser.** Chrome and other browsers are read from the system Now Playing info. A channel name credited as the artist is not treated as the performer when the title is already `Artist - Title`.

**Apple Music.** Read from the system Now Playing info, the same path as a browser. Spotify still wins while Spotify is actually playing.

Advertisement breaks are skipped. Plain, unsynced lyrics are not stretched across the song. If LRCLIB has no timed lyrics, the card shows the track title and “No lyrics”.
